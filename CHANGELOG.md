# Changelog

## 1.0.0 - 2026-10-19

First release.

- Live CPU and NVMe temperatures with a smooth 3-minute graph and color-coded readings.
- Fan thermal target slider, plus fixed fan patterns and boost through `ps5_control`.
- Front LED color picker.
- Always-on-top temperature overlay, pinnable to any screen corner, with adjustable opacity.
- Dark, Light and System themes, and a font picker.
- Rounded, anti-aliased buttons and tabs (uses Pillow when available).
- Settings are remembered between launches.
- App-menu entry and graphical password prompt through `install.sh`.
